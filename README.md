# MESAFARTAI - Logística e Inteligência Assistiva no Combate à Fome

O MESAFARTAI é um projeto que utiliza Inteligência Artificial, Processamento de Linguagem Natural (NLU) e algoritmos de Machine Learning para conectar doadores de alimentos a ONGs e instituições sociais, facilitando a redistribuição de excedentes alimentares e reduzindo o desperdício.

Alinhado ao ODS 2 da ONU — Fome Zero e Agricultura Sustentável, o projeto busca contribuir para a segurança alimentar, promovendo o acesso a alimentos e fortalecendo a solidariedade por meio da tecnologia. Com uma solução conversacional inteligente, o MESAFARTAI automatiza a identificação de produtos, quantidades e validades, direcionando as doações às instituições mais próximas de forma ágil e eficiente.

Nossa missão é transformar o desperdício em oportunidade, conectando tecnologia, sustentabilidade e impacto social para combater a fome.
